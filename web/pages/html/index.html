Tags

Tags in Line - Podem ser utilizadas dentro de blocos

  • ID - Elemento dentro do CSS que tem mais especificidade. Para identificação no CSS utiliza-se "#".
  • p - Tag de texto in line. Algumas alterações de texto podem ser feitas dentro da tag.
  • strong - utilizada para semântica. O código entende que o que está entre a tag ganha mais importânca na leitura. Em leitores de acessibilidade, o texto é interpretado com mais ênfase.
  • i - Tag que deixa o texto em itálico
  • em - Mesma lógica do strong, mas dá ênfase ao texto.
  • a - Utilziada para adicionar links. Usa-se junto com o href="" e configuração de target para definir onde o link será aberto.
  • img - Utilizada para inserir imagens.
  • del - Utilizada para remover algo do código de forma semântica. Exemplo
  • ins - Utilizada para inserir no código de forma semântica. Exemplo.
  • s - Utilizado para riscar o texto. Exemplo
  • u - Utilizado para sublinha o texto. Exemplo
  • small - Diminui o texto. Exemplo
  • sup - Coloca o texto acima. Exemplo.
  • sub - Coloca o texto abaixo Exemplo.
  • q - Utiliado para citações e referências, geralmente acompanhada a tag cite.
  • span - Utilizada para formatar ou manipular textos inline, sem impactar a estrutura na pagina.

Tags em blocos - Ocupam toda a largura disponível e normalmente iniciam em uma nova linha.

  • blockquote - Mesma lógica da tag q, utiliza-se o atributo cite para adicionar a referência.
  • hr - A tag cria uma linha para separar o paragráfo.
  • code - Tag utilizada para representar códigos.
  • pre - Utilizada para manter formatação original do conteúdo.
  • div - Elemento de bloco que quebra paragráfos.
  • nav - Utilizada para criar uma área de navagação com links.
  • ul - Utilizada para criar uma lista não ordenada. Para cada tótico utiliza-se li
  • ol - Lista ordenada
  • dl - Lista de descrição, as tags dt - define o termo ou nome, e dd - define a descrição, detalhe ou o valor correspondente ao termo.

Separação de conteúdo - Tags utilizadas para determinar conteúdos.

  • address - Utilizado para colocar endereços, aqueles que ficam no rodapé da página.
  • article - Utilizado para artigos em site de blogs e etc, posso utilizar també para produtos.
  • aside - Utilizada para criar uma barra lateral no site.
  • footer - Rodapé do site, o footer pode ser utilizado em outros blocos.
  • header - Cabeçalho.

Listas

  • ul - Utilziada para listas não ordenadas.

    Exemplo:

    • Item 1
    • Item 2
  • ol - Lista Ordenada, diferente da ul, possui um identificador em ordem (1, 2, 3...). Pode ser alterado com atributos como o type

    Exemplo:

    1. Item 1
    2. Item 2
  • dl - Utilizada para listas com descrições. Usa-se dt para o termo e para a descrição dd

    Exemplo:

    Macaco
    Animal super incrivel.

Tabelas

Podemos inserir tabelas dentro do nosso arquivo HTML, antigamente o pessoal utilizava as tags de tabela para criar sites.

  • table - utiliza-se para criar uma tabela dentro do documento HTML.
  • thead - utiliza-se para criar uma head dentro do tag table.
  • tbody - utiliza-se para criar o corpo dentro do tag table.
  • tfoot - utiliza-se para criar o rodapé dentro do tag table.
  • caption - utilizada para criar uma descrição da tabela, como se fosse um titulo.
  • th - Utiliza-se para criar colunas do cabeçalho da tabela.
  • tr - Utiliza-se para criar linhas na tabela.
  • td - Utiliza-se para criar colunas no corpo da tabela.
  • colspan="" - Elemento utilizado para determinar quantas celulas da linha vão ser ocupadas (largura da coluna).
  • rowspan="" - Elemento utilizado para determinar quantas celulas da coluna vão ser ocupadas (altura da linha).
