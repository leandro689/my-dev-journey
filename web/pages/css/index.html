Anotações

Comandos

  • width - Define a largura do elemento.
  • height - Define a altura do elemento.
  • background-image - Define uma imagem de fundo para o elemento.

Manipulação de Box Model

  • content - Conteúdo interno do elemento.
  • padding - Defino o espaçamento interno entro o conteúdo e a borda.
  • border - Define a borda ao redor do elemento.
  • margin - Define a mardem da box, não preenche mas afasta do conteúdo.
  • box-sizing - Controla a forma como a largura (width) e a altura (height) de um elemento são calculadas.
  • content-box (Padrão) - O widht e o height consideram apenas o conteúdo. Padding e border são somados ao tamanho final.
  • border-box - O widht e o height já incluem contéudo, padding e border, mantendo o tamanho definido sem aumentar as dimensões externas do elemento.
